# Участие в разработке

Изменения лучше начинать с небольшого описания задачи и ожидаемого поведения.
Для исправления сбоя добавьте воспроизводящую проверку и поясните результат.

## Локальные проверки

```bash
npm ci
npm run build:runner
npm test
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --manifest-path src-tauri/Cargo.toml --locked
```

Настройка окружения описана в [BUILD.md](docs/BUILD.md).

Сетевые сбои проверяйте локальными fixtures. Не используйте игровые серверы
для нагрузочных тестов или искусственных отказов.

В pull request достаточно описать проблему, итоговое поведение и выполненные
проверки. Не добавляйте игровые данные, Wine-префиксы, чужие ресурсы, токены,
пользовательские журналы или настройки аккаунта.
