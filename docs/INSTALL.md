# Установка

Готовые файлы находятся в [GitHub Releases](https://github.com/Lorodn4x/radmir-launcher-linux/releases).
Используйте файлы и контрольные суммы одной версии. AppImage и DEB — два
формата одного лаунчера; доступные форматы перечисляются в релизе.

## AppImage

```bash
chmod +x RADMIR-Standalone-0.1.1-x86_64.AppImage
./RADMIR-Standalone-0.1.1-x86_64.AppImage
```

Если система сообщает об отсутствии FUSE, AppImage можно запустить с распаковкой:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./RADMIR-Standalone-0.1.1-x86_64.AppImage
```

## DEB

Этот формат предназначен для Ubuntu/Debian. Применимость конкретной сборки
к вашей ОС указывается в релизе.

```bash
sudo apt install ./RADMIR-Standalone-0.1.1-amd64.deb
```

APT устанавливает зависимости пакета. Дополнительные зависимости выбранного
Wine и графического пути лаунчер проверяет при подготовке среды.

## Проверка файла

Скачайте SHA256SUMS из того же релиза в каталог с установочным файлом:

```bash
sha256sum --check SHA256SUMS --ignore-missing
```

Команда должна подтвердить выбранный файл как OK. Если контрольная сумма
не совпала, скачайте файл заново.

## Первый запуск

Лаунчер готовит Native PortProton, проверяет файлы игры и необходимые
библиотеки. Подготовка может занять время; прогресс отображается в окне.
Если показан план системных пакетов, просмотрите его и подтвердите
установку стандартным диалогом администратора.

После успешной подготовки выберите сервер, введите никнейм и нажмите
«Играть». Данные игрового аккаунта вводятся в самой игре.

## Настройки среды

В дополнительных настройках Wine/Proton и 3D API выбираются отдельно.
Новейший DXVK/VKD3D требует подходящего Vulkan-драйвера. При несовместимости
используйте объяснение и предложенный лаунчером вариант.

Иллюстрации игровых пресетов в публичной сборке являются схемами,
а не скриншотами игры. Они не подтверждают производительность или визуальное
качество на конкретном GPU.

## Данные пользователя

Лаунчер использует HOME и XDG-каталоги. Закрытие окна не останавливает
активную подготовку и игру. Журналы доступны через сообщение об ошибке
или кнопку открытия журналов.

Перед удалением PortProton сохраните нужные игровые файлы и префиксы.
