# Сторонние компоненты

Исходники этого проекта содержат собственную реализацию лаунчера и PE32
helpers. Компоненты PortProton и файлы игры не включаются в Git.

## Зависимости приложения

Rust/Tauri, SQLite и другие библиотеки используются на условиях их собственных
лицензий. Точные версии фиксируются в Cargo.lock и package-lock.json.
Основные лицензии зависимостей перечислены в dependency-licenses.json.

Часть системных библиотек может включаться в AppImage упаковщиком Tauri.
Окончательный состав установочного файла и соответствующие обязательства
проверяются для каждого релиза; список исходных зависимостей не заменяет
проверку готового пакета.

Готовые пакеты содержат тексты лицензий в
`usr/share/doc/radmir-standalone/licenses` (внутри AppImage) или
`/usr/share/doc/radmir-standalone/licenses` (DEB).
С релизом публикуется архив `third-party-sources.tar.gz`: исходные Cargo
crates и Ubuntu source packages соответствующих версий, контрольные суммы
и инструкции сборки. Для запуска приложения скачивать этот архив не нужно.
Исходники самого лаунчера доступны по тегу релиза в этом репозитории.

## Загружаемая среда

- [PortProton / PortWINE](https://github.com/Castro-Fidel/PortWINE).
- [Wine/Proton-сборки PortProton](https://github.com/Castro-Fidel/wine_builds).
- [DXVK](https://github.com/doitsujin/dxvk).
- [VKD3D-Proton](https://github.com/HansKristian-Work/vkd3d-proton).

URL, версии и SHA256 закреплённых компонентов находятся в
src-tauri/components.lock.json. Эти файлы загружаются при подготовке среды
и сохраняют лицензии своих правообладателей.

## Ресурсы и названия

SVG-оформление репозитория и иллюстрации интерфейса созданы для этого проекта.
Векторные схемы графических пресетов не являются скриншотами игры.
Шрифты поставляются операционной системой и не входят в репозиторий.

RADMIR, игра, серверы и товарные знаки принадлежат соответствующим
правообладателям. Проект не заявляет официальной связи с RADMIR.
